🚀 Quick Install

Standalone zero-Python executables for Windows & Linux, or cross-platform uv tool — all with built-in GitHub Releases auto-updates.

$dir = "$env:LOCALAPPDATA\GPUSentry"; New-Item -ItemType Directory -Force -Path $dir | Out-Null Invoke-WebRequest -Uri "https://github.com/hakanu/gpu_moni/releases/latest/download/gpu-sentry-windows-x64.exe" -OutFile "$dir\gpu-sentry.exe" -UseBasicParsing Start-Process "$dir\gpu-sentry.exe" -ArgumentList "--install-shortcut" -Wait Start-Process "$dir\gpu-sentry.exe"

True WINDOWS_GUI binary (zero background console window), Start Menu shortcut, and automatic SHA256-verified updates via ⚙ Settings → Updates.

uv tool install --force git+https://github.com/hakanu/gpu_moni.git gpu-sentry-tui # 24-bit TrueColor Terminal UI (~38 MB RAM) gpu-sentry # Desktop GUI (auto-falls back to TUI over SSH)

Update anytime with gpu-sentry --update or download the standalone gpu-sentry-linux-x64.tar.gz from GitHub Releases.

# Option A: Run headless agent on any remote machine (no SSH keys required) gpu-sentry --agent # Option B: Agentless SSH (copy your key once to Linux / macOS Mac mini) type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh <user>@<host> "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

Tailscale scanning is OFF by default on fresh installs. Click 🔄 Refresh Tailnet in the app whenever you want to scan.

🔒 Privacy & Zero Tracking

GPU Sentry contains zero analytics, zero user tracking, and zero phone-home. All sensor data and optional CSV/JSONL logs stay strictly on your machine.

  • GitHub Releases check: read-only GET to api.github.com/repos/hakanu/gpu_moni/releases/latest (toggleable in Settings → Updates).
  • Local Ollama lookup: loopback-only 127.0.0.1:11434/api/ps (never leaves your computer).
  • Your own LAN / Tailnet peers: strictly opt-in — Tailscale scanning is OFF by default on fresh installs.

⚠️ Windows, Tailscale & SSH Quirks

Transparent notes on platform behaviors and how GPU Sentry handles them.

Windows OpenSSH flashing console windows during Tailnet scan

Win32-OpenSSH (ssh.exe) calls AllocConsole() when launched with CREATE_NO_WINDOW from a GUI app. GPU Sentry avoids this by keeping Tailscale scanning OFF by default on fresh installs and invoking SSH with -T -n, SSH_ASKPASS_REQUIRE=never, and STARTUPINFO(SW_HIDE) so no terminal window flashes.

Why isn't my Mac mini or Linux Tailnet peer showing up?
  • Click 🔄 Refresh Tailnet to clear cached probe states and re-scan.
  • Agentless SSH uses BatchMode=yes (passwordless). Copy your SSH public key to ~/.ssh/authorized_keys on the remote machine, or run gpu-sentry --agent on it.
  • Note: The macOS App Store edition of Tailscale does not support a Tailscale SSH server — enable macOS System Settings → General → Sharing → Remote Login + SSH keys, or use gpu-sentry --agent.
No background console window & Virtual Desktop behavior

The standalone Windows .exe is a true WINDOWS_GUI executable with zero background terminal. Start Menu & autostart shortcuts use pythonw.exe on uv installs, and the main dashboard stays strictly on the virtual desktop where you open it.
